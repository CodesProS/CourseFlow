# Course data

`courses.json` is a **derived artifact**. It's regenerated by `npm run ingest`
from a local clone of [uw-coursemap-data](https://github.com/twangodev/uw-coursemap-data),
and then committed so that the app can boot without any external dependency.

## Regenerating

```bash
# 1. Clone uw-coursemap-data somewhere on your machine (~300 MB)
git clone https://github.com/twangodev/uw-coursemap-data.git ~/src/uw-coursemap-data

# 2. Run ingest, pointing at the clone
cd backend
UW_COURSEMAP_DATA=~/src/uw-coursemap-data npm run ingest
```

If you put the clone next to `CourseFlow/` (i.e. at `../../uw-coursemap-data`
relative to `backend/`), you can omit the env var.

## What the script does

See `backend/src/scripts/ingest.ts` — it's heavily commented. Summary:

1. Walks `uw-coursemap-data/course/`.
2. Filters to courses in target subjects (`COMPSCI`, `MATH`, `PHYSICS`,
   `ENGL`, `HISTORY`, `KINES`) that have live meeting data.
3. Transforms each record: normalizes the code, maps breadth/gen-ed flags,
   turns session timestamps into weekly recurring patterns, computes
   average GPA from the historical grade distribution.
4. Writes sorted output to `backend/data/courses.json`.

## Known simplifications

- Only lecture (LEC) sections are kept. Lab/discussion coupling is future work.
- Cross-listed courses use the primary subject from `course_reference.subjects[0]`.
- Breadth is inferred from subject (see `BREADTH_BY_SUBJECT` in `ingest.ts`)
  because the real UW breadth codes aren't exposed in uw-coursemap-data.
